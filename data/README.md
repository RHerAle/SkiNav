# SkiNav Resort Graph Database

These files form a Derivative Database of OpenStreetMap data, © OpenStreetMap contributors (https://www.openstreetmap.org/copyright), published under the Open Database License (ODbL) 1.0. Read the full text in `LICENSE-DATA` and at https://opendatacommons.org/licenses/odbl/1-0/. Additional transit data (ski bus connections) carries these same terms.

Source: OpenStreetMap (extracted October 2026). Processing: topological graph conversion of OSM pistes and aerialways into weighted directed graphs across 82 ski resorts (31 in Spain, 48 in Italy, 2 in France, 1 synthetic network).

Each release tag of SkiApp offers the copy of the Derivative Database under section 4.6 of the ODbL.
